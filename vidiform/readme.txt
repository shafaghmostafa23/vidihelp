Official VidiForm theme: two independent content systems — Help Center and Blog — each with its own admin panel.

== Description ==

* Help Center (/help/): categories, sub-categories, guides built from ordered sections (text with inline
  guide links, image/video/audio, colored hints, feature popups, embedded VidiForm, template preview),
  search, breadcrumbs, prev/next and related guides.
* Blog (/blog/): featured posts, categories, tags, authors, search, related posts, share buttons, comments.
* Separate admin menus: «مرکز راهنما» and «وبلاگ», plus Settings → ویدی‌فرم for shared options.
* Light & dark mode (design tokens), RTL, responsive, accessible, SEO-ready (compatible with Yoast,
  Rank Math, AIOSEO, SEOPress, The SEO Framework).

== Installation ==

1. Appearance → Themes → Add New → Upload Theme → choose vidiform-wordpress-theme.zip → Install → Activate.
2. On activation the theme creates the «وبلاگ» posts page and a routing front page, and sets
   permalinks to /blog/%postname%/ if they were "Plain".
3. مرکز راهنما → تنظیمات → «بارگذاری ساختار پیش‌فرض» imports the default Help Center structure.
4. Settings → ویدی‌فرم: panel URL, which section the site root opens, default light/dark mode, Jalali dates.
